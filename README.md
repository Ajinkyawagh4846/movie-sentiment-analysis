# 🎬 Movie Review Sentiment Analysis

A Machine Learning project that automatically classifies movie reviews as **Positive** or **Negative** using Natural Language Processing.

## 📊 Project Overview

This project analyzes sentiment in movie reviews using the **IMDB Dataset** (50,000 reviews) and achieves **85.87% accuracy** with a Logistic Regression model.

## 🎯 Key Results

- **Accuracy:** 85.87%
- **Dataset:** 50,000 IMDB movie reviews
- **Positive Reviews:** 50.8%
- **Negative Reviews:** 49.2%

## 🛠️ Technologies Used

- **Python 3.x**
- **scikit-learn** - Machine Learning
- **pandas & numpy** - Data manipulation
- **TF-IDF** - Feature extraction
- **Logistic Regression** - Classification model

## 🚀 How to Run

1. **Clone the repository**
```bash
   git clone https://github.com/Ajinkyawagh4846/movie-sentiment-analysis.git
   cd movie-sentiment-analysis
```

2. **Install dependencies**
```bash
   pip install pandas numpy scikit-learn
```

3. **Run the model**
```bash
   python train_model.py
```
